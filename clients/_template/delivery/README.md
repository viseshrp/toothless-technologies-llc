# Delivery workspace

AI technical roles own this directory. The human CPO does not need to code.

Before implementation, add:

- a plain-language technical plan;
- architecture and data-flow diagrams;
- technical risks and alternatives;
- the approved PRD and experience references; and
- named file or component ownership.

During implementation, keep the locally runnable MVP, tests, synthetic fixtures,
and setup instructions here. Update `BUILD_LOG.md` with checks and results.

The CPO resolves product ambiguity and accepts product behavior. The CTO owns
architecture, security, engineering quality, and technical readiness.
