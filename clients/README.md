# Account engagements

Each directory contains one isolated Toothless Technologies LLC engagement.
Current engagements are internal speculative work based on public market
signals. A named target organization is not a client and has not requested,
reviewed, or endorsed the work.

## Create an engagement

1. The CEO selects a Sales-generated internal opportunity.
2. Revenue, Finance, Technology, Operations, and Legal complete qualification.
3. Copy `_template/` to a lowercase, hyphenated slug such as
   `2026-09-target-account-product-mandate/`.
4. Replace every bracketed placeholder in the copied folder.
5. Keep the independent-work disclosure at the top of `README.md` and
   `BRIEF.md`.
6. Add only active roles to `TEAM.md` and assign one owner per output.
7. Run `python3 scripts/validate_repo.py` before committing.

Never record account data in `_template/` or mix artifacts between engagement
folders.
