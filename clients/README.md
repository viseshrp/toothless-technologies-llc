# Practice engagements

Every directory here represents one fictional educational engagement. Real
company names may appear, but no directory represents a real client, request,
lead, or affiliation.

## Create a case

1. Let the AI CEO select a Sales-generated fictional opportunity.
2. Copy `_template/` to a lowercase, hyphenated slug such as
   `2026-09-example-company-checkout/`.
3. Replace every bracketed placeholder in the copied folder.
4. Keep the disclaimer at the top of both `README.md` and `BRIEF.md`.
5. Add only the roles needed for the current stage to `TEAM.md`.
6. Run `python3 scripts/validate_repo.py` before committing.

Never record case data in `_template/`, and never put one case's artifacts into
another case's folder.
